# Method sheets

Each analysis tool has one sheet in this folder, named after the button of the tool (for example
`backscatter-change.md`). A sheet states:

1. The reference of the published method.
2. The input layer, with its name in the NISAR product and its unit.
3. The formula.
4. The unit of the result and the range and colour scale of its legend.
5. How to read the result.
6. The source program with which the result was compared, its version and the largest difference found.
