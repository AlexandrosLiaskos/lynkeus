# Research note: Analysis and Help tabs

Before a tool of this part is built, this note records for it:

1. The NISAR product specification of its input layer, with the section or page: the name of the layer, its
   unit, its value for cells without data and its masks.
2. The publication of its method, with the section or page.
3. The source program with which its result is compared, with its version.
4. The limits found, and whatever could not be confirmed.
5. The date on which each source was read.
